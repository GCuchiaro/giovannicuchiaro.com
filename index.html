02 / projetos

Coisas que construí.

Quase todas nasceram de uma tarefa repetitiva que alguém fazia à mão. As telas são das ferramentas reais, rodando com empresas e números fictícios.

01ferramenta interna

Analisador Financeiro

Lê o balancete exportado do sistema contábil, calcula os indicadores e monta o painel de saúde financeira, com rascunho de parecer. Os dados brutos não ficam guardados.

Python · FastAPI · React

02automação

Gerador de Orçamentos

Consulta o CNPJ, calcula o honorário pela tabela do escritório e gera a proposta em PDF, sempre no mesmo padrão.

Python · HTML para PDF

03IA

Gerador de Carrosséis

Escreve o conteúdo com IA na voz da marca e exporta os slides prontos para o Instagram, vários de uma vez.

Next.js · API do Claude · Canvas

04ferramenta para clientes

HTML · JavaScript
