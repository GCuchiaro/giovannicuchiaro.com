# giovannicuchiaro.com

Site pessoal de Giovanni Cuchiaro: trajetória, projetos, ferramentas, escritos e currículo.

Site estático (HTML + CSS), publicado pelo GitHub Pages com o domínio `giovannicuchiaro.com` (arquivo `CNAME`).

## Estrutura

- `index.html` — página inicial (trajetória, projetos, ferramentas, escritos, contato)
- `cv/` — currículo, com PDF em `assets/curriculo-giovanni-cuchiaro.pdf`
- `escritos/` — textos (`escritos/synergy-2026/`)
- `assets/` — estilo, script, logos, telas dos projetos e imagem de compartilhamento
- `404.html` — página de erro

## Como editar

Os arquivos podem ser editados direto no GitHub. Cada alteração na branch `main` é publicada em 1 a 2 minutos.
